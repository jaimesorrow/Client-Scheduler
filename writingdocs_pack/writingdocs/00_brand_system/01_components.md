# Component Library (MVP)

## Buttons
- Primary: filled accent `#C9A24D` + ink text `#0B0B0F`
- Secondary: outline divider `#E7E7EC`
- Destructive: filled danger `#C62828` + white text
- Disabled: divider fill + muted text

## Inputs
- TextField: label + placeholder + helper/error
- Focus ring: 2px accent @ ~30% opacity
- Error border: danger

## Common patterns
- **Empty state:** icon + headline + one sentence + one CTA
- **Skeleton loading:** list rows + cards
- **Status pills:** scheduled / completed / cancelled / no_show
- **Audit timeline:** newest first; action + actor + timestamp + meta
